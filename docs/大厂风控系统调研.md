# 大厂风控系统调研

> 结论：大厂风控系统的形态高度趋同——「**采集SDK + 三层特征平台 + 规则引擎与模型并行的决策中枢 + 可视化策略运营**」四件套，演进路径都是 硬编码 → 规则引擎 → 规则+模型 → 智能化。radar 的定位相当于这套体系的「规则引擎 + 实时指标」两层，约等于大厂 2015–2016 年代水平（对标京东天盾 1.0/2.0），做业务风控底座可用，缺的部分见文末对照。

## 一、共性架构（各家拆完都长这样）

| 层 | 干什么 | 典型实现 | 关键指标 |
|---|---|---|---|
| 数据采集 | 还原「请求背后是谁」：设备指纹、IP、行为轨迹 | 客户端 SDK + 网关旁路 | 设备伪造识别率 99%+（腾讯） |
| 特征平台 | 原始数据 → 可计算信号（近1小时登录次数、同设备关联账号数） | 实时：Flink+Redis 毫秒级滑窗；近线：Kafka 秒级；离线：Spark 天级画像 | 分层计算，状态设 TTL 防爆炸 |
| 决策中枢 | 规则前置过滤（可解释、<10ms）→ 模型推理（50–100ms）→ 决策编排（DAG） | 自研 DSL 规则引擎（Groovy/Aviator 编译执行）+ PMML/在线模型服务 | 输出四态：放行 / 二次验证 / 人工复核 / 拒绝 |
| 策略运营 | 可视化零代码配置、灰度发布、A/B 实验、影子流量回放、自动降级盖帽 | 规则引擎后台 + 实验平台 | 京东：零代码解决 90% 对抗问题 |
| 模型与分析 | 评分卡/树模型打分、GNN 图计算挖团伙、知识图谱关联分析、AutoML 自动迭代 | XGBoost/LightGBM 在线推理 + 图计算离线挖掘 | 蚂蚁：团伙识别、策略智能推荐 |

## 二、各家方案要点

| 厂商 | 系统 | 核心思路 | 代表做法 |
|---|---|---|---|
| 美团 | Zeus（宙斯） | 降接入成本 + 逻辑模板化复用 | ① 挂在用户中心/订单中心/收银台等通用节点，业务无感接入；② 扩展函数、累计因子（高频计数逻辑封装）、决策表因子三类模板；③ 外卖风控 Flink SQL + Hudi 流批一体 |
| 蚂蚁 | AlphaRisk / DecisionX（五代演进） | 分层流量漏斗 + 智能化 | ① 五级分层：T0 终端识别 → T1 快速放行可信流量 → T2 深度规则+模型 → T3 异步深度学习 → T4 离线；② 旁路流量在新决策树上影子重放，改动不生效但能验证全局影响；③ 拦截率异常波动自动降级/盖帽；④ 图谱+人机协同分析 |
| 腾讯 | 天御（云产品化输出） | 三道防线纵深 | 流量端智能清洗 → 设备端可信标识（假人/假机识别）→ 业务端实时决策引擎；识别 <200ms、单点 20 万 QPS、SaaS 1–2 周接入 |
| 京东 | 天盾 → 星盾决策引擎 | 三代演进 + 中台化输出 | 1.0 Groovy 原子规则 → 2.0 规则+维度+设备指纹+模型并行 → 3.0 食蚁兽实时指标平台 + Rete 规则 + PMML 模型 + Flink；组织上前台（贴业务）+中台（共建共享），可视化分人群配置（业务员傻瓜式/运营可视化/复杂场景研发代码） |
| 字节 | 安全中心 → 火山引擎输出 | 模型矩阵 + 黑产特征库 | GRU/LightGBM/Transformer/GraphSage 模型融合；无监督团伙挖掘（不依赖标签）；十亿级黑产设备/账户/IP 特征沉淀 |

## 三、演进规律（一句话版）

1. **规则形态**：硬编码 if-else → 表达式引擎 → 可视化决策树/决策表 → AI 自动生成策略。
2. **计算形态**：同步单点 → 事件驱动 + 流计算（Flink 成事实标准）→ 流批一体。
3. **决策形态**：纯规则 → 规则+模型并行 → 分层漏斗（好流量秒放，可疑流量才走重计算）。
4. **组织形态**：业务内嵌 → 独立风控平台 → 风控中台/云产品对外输出。
5. **安全网**：全行业共识——灰度、影子回放、自动降级、A/B 缺一不可（策略本身就是风险源）。

## 四、与 radar 的差距对照（二开参考）

| 能力 | radar 现状 | 大厂标配 | 二开优先级 |
|---|---|---|---|
| 规则引擎 | ✅ Groovy 规则 + 激活分层 | 同 | 不动 |
| 实时指标 | ⚠️ abstraction 查 Mongo 聚合（每次现算，性能差） | Flink 预计算 + Redis 点查 | 高 |
| 名单服务 | ✅ 黑白名单内存缓存 | 同 | 不动 |
| 模型 | ⚠️ TF 1.12 DNN（已过时，Apple Silicon 跑不了） | PMML/LightGBM 在线推理 | 中 |
| 设备指纹 | ❌ 无 | SDK 采集 + 信誉库 | 高（业务风控必备） |
| 图计算/团伙 | ❌ 无 | GNN + 知识图谱 | 低（规模大了才有价值） |
| 配置热更新 | ❌ 改配置要重启进程 | 热加载 + 灰度 | 高（运营效率瓶颈） |
| 安全网 | ❌ 无灰度/回放/降级 | 标配 | 中（出事故前不疼） |
| 事件通道 | ⚠️ HTTP 单接口 + kafka-demo | Kafka 事件总线标准接入 | 高 |
